# Generated Code Policy

Nodal's public model generator converts a user-supplied canonical descriptor
into ordinary C# source files. The generated source belongs to the user who
supplied the model and may be used, modified, and distributed under terms that
user selects. Running the generator does not, by itself, require the generated
application code to use the MPL-2.0 license.

The Nodal Framework libraries, generator implementation, and copied portions
of Nodal source remain governed by their own license. Applications that
reference Nodal packages must continue to satisfy the licenses of those
packages. This policy does not grant rights to third-party source schemas,
names, data, trademarks, or provider software.

Generated files contain a descriptor fingerprint and generator version for
reproducibility. They must not contain source credentials, sample rows, or
provider tokens.

This project policy is an engineering and distribution statement, not legal
advice.
