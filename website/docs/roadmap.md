# Roadmap

P0 delivered the query, tracking, mutation, and migration foundation. P1 delivered typed routes, centrality and community contracts, native Neo4j shortest paths, weighted GDS path compilers, TigerGraph installed-query execution, runtime capability discovery, Neo4j projection lifecycle management, typed options, and compiled analytics factories.

## Next focus

- Expand per-version live GDS and TigerGraph installed-query certification.
- Harden public APIs through real application samples and compatibility tests.
- Expand migration diffing and lifecycle tooling.
- Design P2 analytics write/mutate semantics without bypassing tracking and unit-of-work guarantees.
- Build event-driven mutation and outbox integration points.
- Publish capability metadata that tools and coding agents can consume safely.
- Establish versioned documentation and stable package releases.

Roadmap items describe intent, not a compatibility promise. Track implementation status in the [GitHub repository](https://github.com/Greenstone-Research-Lab/NodalFramework).
