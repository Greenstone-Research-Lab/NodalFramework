# Security Policy

## Supported releases

The latest published Nodal Framework pre-release is eligible for security
fixes. Earlier alpha and beta packages may be superseded rather than patched in
place because NuGet packages are immutable.

## Reporting a vulnerability

Do not disclose a suspected vulnerability in a public issue. Use the
repository's private vulnerability reporting flow:

https://github.com/Greenstone-Research-Lab/NodalFramework/security/advisories/new

Include the affected package and version, reproduction conditions, expected
impact, and any proposed mitigation. Do not include production credentials,
customer data, or third-party personal data.

The maintainers will acknowledge a complete report, assess severity and
affected versions, coordinate a remediation and release, and publish an
advisory when disclosure is safe.
